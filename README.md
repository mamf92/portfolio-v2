# 🧑‍💻 Martin Fischer – Front-End Developer Portfolio

This is my second-year **Portfolio 2 Course Assignment** as part of the Front-End Development programme at Noroff. It’s a single-page application portfolio site showcasing three of my graded projects from the second year:  

- [CSS Frameworks – SO-ME - A social media website](https://mamf92.github.io/semester-project-1/)
- [JavaScript Frameworks – Scretcher Online Shop](https://mamf92.github.io/rainydays-v2/)
- [Semester Project 2 - The Wexford Gallery Auction House](https://github.com/mamf92/wexfordgallery))

The purpose of this project is to self-assess, reflect on what I’ve learned so far, and demonstrate how my skills have developed throughout the two years at Noroff.

---

## 📋 Description

The goal was to build a clean, responsive, and accessible portfolio site using only **React**, **TypeScript**, and **Tailwind CSS**. The site includes teaser cards for three major assignments with links to the README, the deployed demo, and a details page about the project.

In addition to building the site, I wrote a reflection report discussing:
- Improvements I’ve made
- What I would improve further
- What I’ve learned from each project
